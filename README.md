## Current Project

### Immera

A full-stack reading application for language learners, built around **React Native + Go + PostgreSQL**.

The backend is being developed as a production-oriented modular monolith with:

- Go + chi
- PostgreSQL + pgx
- REST APIs
- JWT authentication & refresh tokens
- database migrations
- translation caching
- structured service / repository / handler layers
- Docker
- graceful shutdown & health checks

The mobile client is designed around reading, contextual translation, personal vocabulary, notes and reading progress.
